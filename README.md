# 🎮 Mini Game Lab - 五款小游戏大厅

一个包含5种独特解锁方式和5款不同类型小游戏的互动网页作品。

## 🌐 在线体验

### GitHub Pages 访问方式：

1. **启用 GitHub Pages**：
   - 进入仓库的 `Settings` > `Pages`

## 🎯 游戏特色

### 主菜单 - 5种独特解锁方式

| 入口 | 交互方式 | 说明 |
|------|---------|------|
| ⚡ 闪电按钮 | 充能解锁 | 鼠标悬停充能至100% |
| 🍉 水果 | 拖拽解锁 | 拖动小刀到水果上释放 |
| 🚪 滑动门 | 滑块解锁 | 拖动滑块到最右端 |
| 📖 记忆书 | 文字解锁 | 输入密码 "MEMORY" |
| 🚀 星球 | 旋转解锁 | 拖动星球旋转一圈(360°) |

### 五款小游戏

#### 1. ⚡ 闪电反应测试
- **类型**：反应速度类
- **玩法**：点击高亮的按钮
- **时长**：30秒
- **目标**：获得最高分数

#### 2. 🍉 切水果
- **类型**：动作/消除类
- **玩法**：鼠标拖动画出刀光切水果
- **时长**：45秒
- **注意**：避开炸弹💣（-3分）

#### 3. 🏃 迷宫挑战
- **类型**：迷宫/躲避类
- **操作**：方向键 ↑↓←→
- **目标**：躲避敌人到达终点🏁
- **记录**：用时和重置次数

#### 4. 🧠 记忆翻牌
- **类型**：记忆配对
- **玩法**：点击卡片找相同颜色
- **数量**：12张卡片（6对）
- **目标**：用最少步数完成配对

#### 5. 🚀 太空躲避
- **类型**：生存/躲避类
- **操作**：左右方向键 ←→
- **玩法**：控制飞船躲避陨石
- **目标**：生存越久分数越高

## 🕹️ 操作指南

### 键盘控制
- **迷宫游戏**：方向键 ↑↓←→
- **太空躲避**：← → 左右移动
- **记忆书解锁**：键盘输入 + Enter

### 鼠标控制
- **闪电充能**：悬停鼠标
- **小刀拖拽**：按住拖动
- **滑块拖拽**：按住拖动
- **星球旋转**：按住拖动
- **切水果**：按住鼠标拖动
- **翻牌/点击**：鼠标点击

### 通用功能
- 每个游戏左下角都有 **← 返回大厅** 按钮
- 可随时切换到其他游戏

## 🎯 设计理念

- **多样化交互**：每个入口都有完全不同的交互方式，提供新鲜感
- **渐进式探索**：玩家需要主动探索才能解锁所有游戏
- **即时反馈**：所有操作都有清晰的视觉和动画反馈
- **可爱风格**：统一的卡通风格，深色背景+亮色元素

## 📝 开发笔记

- 所有游戏逻辑封装在独立函数中
- 使用 `currentScene` 变量管理场景切换
- Canvas 渲染采用 requestAnimationFrame 循环
- 事件监听统一管理，支持鼠标和键盘
- 碰撞检测使用简单的圆形和矩形碰撞算法
